How to Make Public Wi-Fi Safer

Simple habits that reduce risk when using Wi-Fi away from home.

Verify the network

Ask staff for the exact network name when possible. Attackers can create similarly named networks to trick users.

Prefer HTTPS

Modern websites normally use encrypted HTTPS connections. Check that the browser shows a secure connection before entering sensitive information.

Avoid sensitive transactions

When practical, wait until you are on a trusted network for banking or other highly sensitive activity.

Turn off sharing

Disable unnecessary device discovery and file sharing when you are on an unfamiliar network.

Use updates and strong passwords

Keep your operating system and browser updated and use unique passwords. A password manager can help.

Forget old networks

Remove public networks you no longer use so your device does not automatically try to reconnect later.
